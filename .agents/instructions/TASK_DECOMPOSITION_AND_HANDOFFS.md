# Task Decomposition and Handoffs

## Decomposition

Break work by engine boundary, not by file count.

## Handoff packet

A handoff must include:

- Objective.
- Current state.
- Evidence.
- Decisions made.
- Assumptions.
- Blockers.
- Requested output.
- Deadline or priority, if known.

## Handoff rule

Do not hand off vague work. Convert vague work into a precise subtask first.
