# Versioning and Decision Records

## Required for

Create a decision record for changes to:

- SRPL syntax or semantics.
- Type system.
- Catalog object model.
- Protobuf contracts.
- QUIC frame layout.
- WAL record format.
- Page, segment, or manifest format.
- Transaction state machine.
- Security, IAM, audit, backup, or HA/DR policy.
- Agent, skill, or hook behavior that blocks user actions.

## Decision record fields

- Title.
- Status.
- Context.
- Decision.
- Consequences.
- Alternatives rejected.
- Affected components.
- Validation plan.
- Rollback plan.
