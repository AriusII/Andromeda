# Andromeda Agent Assets

`.agents` contains reusable agent-facing assets that are not Codex runtime hooks.

| Path | Purpose |
|---|---|
| `skills/` | Focused `SKILL.md` capabilities for repeatable Andromeda work. |
| `instructions/` | Stable standards for authoring, review, research, security, SRPL, storage, recovery, and governance work. |
| `registries/` | Governance registries, quality gates, risk policy, and mapping data. |

`.codex/config.toml` and `.codex/agents/*.toml` are the source of truth for runnable Codex agents. `.agents/skills/*/SKILL.md` is the source of truth for skills.
