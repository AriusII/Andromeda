Ce rapport détaille les architectures GPU NVIDIA et AMD pertinentes entre 2018 et 2026, l’écosystème Rust pour l’accélération GPU et des recommandations pratiques pour intégrer ces technologies dans le moteur SGBDR Andromeda. Il met l’accent sur la performance en double précision, la capacité mémoire, l’efficacité énergétique et propose des pistes concrètes pour exploiter les frameworks Rust tels que `wgpu`, `krnl`, `cuda_std` et `cudarc`.
