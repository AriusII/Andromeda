# Research Synthesis Standard

## Purpose

Use when summarizing academic, standards, or vendor research.

## Method

1. Separate consensus from frontier research.
2. Identify primary sources.
3. Identify vendor-specific assumptions.
4. State whether the source is stable, preview, experimental, or deprecated.
5. Map the source to Andromeda only if it can be defined, bounded, observed, versioned, tested, replayed, and disabled.

## Output

Include recommendations, rejected options, and open research questions.
