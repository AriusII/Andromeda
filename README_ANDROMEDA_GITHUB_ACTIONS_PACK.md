# Andromeda GitHub Actions Pack 2026

This pack provides GitHub Actions automation for the Andromeda Rust workspace.

## Contents

- CI quality gates.
- Rust matrix validation.
- Protobuf contract governance.
- gRPC exclusion policy.
- Security scanning.
- Supply-chain validation.
- Nightly deep validation.
- Fuzzing hooks.
- Performance smoke benchmarks.
- Linux x64 and ARM64 cross-builds.
- Release packaging with checksums and artifact attestations.
- GitHub hygiene checks.
- Copilot governance.

## Install

Extract this archive at the root of the repository.

```bash
unzip Andromeda_GitHub_Actions_Pack_2026.zip -d .
```
