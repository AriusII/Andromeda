# Testing

> **Status:** Testing index
> **Scope:** `docs/testing/`

## Purpose

This folder defines Andromeda's validation strategy, release gates, fuzzing, property testing, and
crash/recovery expectations. These documents guide evidence collection but do not replace crate-owned
tests or retained release artifacts.
