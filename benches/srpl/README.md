# SRPL Benchmark Suite

Benchmarks for SRPL compilation and execution performance.

## Scenarios

- Procedure compilation time
- Type checking latency
- Binder resolution time
- Cardinality derivation time
- Procedure cache hit ratio

## Hardware Profiles

Specify when adding benchmarks:
- CPU model
- Procedure complexity metrics
- Database schema size

## Non-Goals

Benchmarks are advisory only. Must not replace:
- Type system correctness tests
- Cardinality validation
- Execution result verification
